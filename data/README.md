# Data

The raw datasets are not included in this repository. They are public, but their licences belong to the original providers. Place the files below in `data/raw/`, or point the `HDIOD_DATA_DIR` environment variable to another folder.

| Dataset | Source | File(s) to place in `data/raw/` |
|---|---|---|
| Pima Indians Diabetes | [Kaggle: uciml/pima-indians-diabetes-database](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database) | `diabetes.csv` |
| Thyroid / Annthyroid | [UCI Thyroid Disease](https://archive.ics.uci.edu/dataset/102/thyroid+disease) | `ann-train.data`, `ann-test.data` |
| Arrhythmia | [UCI Arrhythmia](https://archive.ics.uci.edu/dataset/5/arrhythmia) | `arrhythmia.data` |
| Vertebral Column | [UCI Vertebral Column](https://archive.ics.uci.edu/dataset/212/vertebral+column) | downloaded automatically with `ucimlrepo` |
| WPBC | [UCI Breast Cancer Wisconsin (Prognostic)](https://archive.ics.uci.edu/dataset/16/breast+cancer+wisconsin+prognostic) | downloaded automatically with `ucimlrepo` |
